📖 Synthèse : tout ce qu'il faut retenir

Cette leçon récapitule toutes les transformations du discours rapporté. Voici le tableau complet des changements à effectuer lors du passage du discours direct au discours indirect.

🔹 1. Les pronoms

  • 1re personne → 3e personne : je → il/elle, nous → ils/elles
  • 2e personne → selon le contexte : tu → je / il / elle (selon qui parle)
  • Adjectifs possessifs : mon/ma/mes → son/sa/ses ; notre/nos → leur/leurs

🔹 2. Les temps (quand le verbe introducteur est au passé)

Remarque : Si le verbe introducteur est au présent ou au futur, les temps ne changent pas.

🔹 4. Les types de phrases

  • Déclarative : introduite par que → Il dit qu'il viendra.
  • Interrogation totale (oui/non) : introduite par si → Il demande si elle viendra.
  • Interrogation partielle : le mot interrogatif est conservé → Il demande où elle va.
  • Impérative : de + infinitif → Il m'ordonne de partir.

🔹 5. Les types de discours

  • Discours direct : paroles citées entre guillemets, avec les temps et pronoms d'origine.
  • Discours indirect : paroles rapportées avec que / si / mot interrogatif / de + infinitif, avec les transformations.
  • Discours indirect libre : mélange subtil entre récit et paroles rapportées, sans verbe introducteur explicite (procédé littéraire).

🔹 6. Les verbes introducteurs

  • Déclaratif : dire, déclarer, affirmer, annoncer, préciser, ajouter, répondre, raconter, avouer, reconnaître…
  • Interrogatif : demander, se demander, s'informer, s'enquérir, vouloir savoir, ignorer…
  • Injonctif : ordonner, commander, demander, conseiller, supplier, prier, interdire…
