📖 La règle

🔹 1. Qui raconte ? Le narrateur

Dans un récit, celui qui raconte s'appelle le narrateur. Ce n'est pas forcément l'auteur !

  • Le narrateur peut être un personnage de l'histoire : le récit est alors à la 1ère personne (« je », « nous »).
  • Le narrateur peut être extérieur à l'histoire : le récit est alors à la 3e personne (« il », « elle », « ils »).
  • Le « je » du narrateur n'est pas le « je » de l'auteur : c'est un rôle inventé pour raconter.

🔹 2. Les mots de reprise

Pour éviter les répétitions et assurer la cohérence du texte, on remplace un nom (ou un groupe nominal) par un mot de reprise.

  • Pronoms personnels : il, elle, ils, elles, le, la, les, lui, leur…
  • Pronoms démonstratifs : celui, celle, ceux, celles…
  • Pronoms possessifs : le mien, le tien, le sien…
  • Synonymes et périphrases : l'animal, la bête, la fillette…

💡 Attention : un mot de reprise doit toujours renvoyer clairement à un mot déjà cité (l'antécédent).
