📖 Les modes et leurs temps

Le verbe varie selon le mode (indicatif, subjonctif, conditionnel, impératif) et le temps. Chaque mode exprime une attitude du locuteur (réalité, souhait, condition, ordre).

🔹 Indicatif

  • Présent (je dis, tu racontes) : action en cours, habitude, vérité générale.
  • Imparfait (disais, souriait) : description, habitude passée, arrière-plan.
  • Passé simple (furent anéanties, apporta) : action ponctuelle et achevée.
  • Plus-que-parfait (avait été, s'en était allé) : antériorité dans le passé.
  • Futur simple (faudra) : action future.

🔹 Subjonctif

  • Présent (que je comprenne, qu'il vienne) : souhait, obligation, doute.
  • Passé (que j'aie compris) : antériorité par rapport au verbe principal.

🔹 Conditionnel

  • Présent (je voudrais, il faudrait) : politesse, hypothèse, futur dans le passé.
  • Passé (j'aurais voulu) : regret, reproche, hypothèse non réalisée.

🔹 Impératif

Présent (raconte, écoute) : ordre, conseil, prière. Pas de sujet exprimé.

💡 Le choix du mode dépend du verbe introducteur (croire, penser → indicatif ; vouloir, il faut que → subjonctif ; si → conditionnel/indicatif).
